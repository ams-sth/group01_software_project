# Week 5 — Shanti (Tester/DBA)

Attended the group meeting and discussed the current progress of the project, including which features had been completed and what work was still in progress.

We also discussed how developers and testers should communicate while writing and reviewing backend testing scripts. The team agreed that testers should stay informed about new features, endpoint changes, and expected behaviour so that test scripts can be written against the latest implementation.

This communication process will help keep the developers and testers in the loop, make it easier to report issues, and ensure that testing keeps pace with the project development.
